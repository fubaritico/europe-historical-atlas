# Glossaire

> Les termes en anglais, parce que ce sont ceux qu'on voit dans le code et les docs. Définitions en
> français. Une ligne chacun.
>
> **Règle de travail, posée par le dev le 2026-09-22 : tout mot nouveau atterrit ici, tout de suite.**
> Ce document est ce qui permet qu'on se comprenne. Un terme employé en réponse et absent d'ici est une
> dette — l'ajouter fait partie de la réponse, pas d'un rangement ultérieur.
>
> **Ce qui entre, précisé par le dev le 2026-09-24 :** de la **cartographie** et du **logiciel lui-même**
> — ses objets, ses gestes, ses écrans, ses formats. Rien d'autre. Le vocabulaire d'outillage général
> (build, paquets, cache, CI) **n'y a pas sa place** : il est connu, il ne nous est pas propre, et le
> noyer dedans ferait perdre au glossaire ce qui le rend lisible. Dans le doute : _est-ce qu'un
> développeur qui arrive comprendrait ce mot sans nous ?_ Si oui, il n'entre pas.

## Les formats et la géométrie

| terme                           | ce que c'est                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **GeoJSON**                     | Format standard pour de la géométrie géographique. Le format d'origine de nos deux sources.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **RegionPayload**               | **Notre** format. Les deux sources y sont converties. `{source, year, bbox, regions[]}`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **claim** / revendication       | Ce qu'un pays tient une année donnée, sous forme d'anneaux fermés.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **index d'ancre**               | La place d'un point dans la table commune des points. Un anneau est une liste d'index, pas de coordonnées — c'est ce qui rend le partage possible.                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **bout partagé**                | Une suite d'ancres que deux tracés ont en commun. **C'est la frontière entre leurs deux pays**, trouvée en comptant combien de tracés tiennent chaque ancre. Tenue par 2 tracés, la paire est nommée sans autre question. Tenue par **1 seul**, il faut encore demander qui tient le sol de l'autre côté — voir **inclusion**.                                                                                                                                                                                                                                                        |
| **dériver**                     | Obtenir sans l'avoir dessiné. On dessine des **contours de pays** ; les **frontières** sont ensuite calculées à partir d'eux. C'est pour ça qu'aucune frontière n'est stockée : elle serait alors une seconde version de ce que les contours disent déjà, et les deux finiraient par se contredire.                                                                                                                                                                                                                                                                                   |
| **inclusion**                   | **« Est-ce que ce contour est à l'intérieur de celui-là ? »** Rien de plus. Ça sert deux fois : décider si un anneau est un trou ou un second morceau, et trouver le voisin d'un bout tenu par un seul tracé. C'est ce qui rend sa frontière au vassal dessiné dans son suzerain : ses points sont à lui seul, donc le comptage dit « rien de l'autre côté » — et l'inclusion répond « la France ». _(Le code disait `containment`, renommé le 28/09 parce que le mot ne se lisait pas.)_                                                                                             |
| **table des frontières**        | Le tableau qui dit ce qu'est chaque frontière : son type (convenue, de fait, contestée, indéterminée), sa **main**, sa source, une note. Une ligne par couple de pays. **Aucune coordonnée** — le bout partagé se désigne déjà tout seul.                                                                                                                                                                                                                                                                                                                                             |
| **registry.json**               | Le fichier des identités **d'une année** — `years/<année>/registry.json`. Rien n'est partagé entre années. Voir `cartographer/format.md`.                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **ring** / anneau               | Une ligne fermée. Un pays = un ou plusieurs anneaux (ses morceaux et ses trous).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **tracé ouvert** / open outline | Un contour qu'on a arrêté sans le fermer (décision du dev, 05/11 au soir). Il entre dans la carte quand on change de pays, se reprend à la plume par une de ses **extrémités**, et se ferme en cliquant l'autre. Il se **remplit comme s'il était fermé** par un trait droit entre ses deux extrémités — comme Illustrator remplit un tracé ouvert — mais ce trait n'est **ni dessiné ni une frontière**. Deux points lui suffisent, trois pour un anneau fermé. Dans le fichier : `open`, les positions des anneaux ouverts d'un pays (`files/plans/cartographer/open-outlines.md`). |
| **fiche** / sheet               | Tout ce qu'on remplit dans le formulaire d'une entité politique : nom, nom court, rang, statut, suzerain, dates, couleur, identifiant Wikidata — jamais son identifiant, jamais son tracé. ‹⌘C› copie l'entité entière, fiche et tracé ; ‹⇧⌘C› sa fiche seule, qui se colle champ par champ sur une entité d'une autre carte (décision du dev, 05/11 au soir).                                                                                                                                                                                                                        |
| **partie** / piece              | Ce que devient une copie de points (‹⌘C›) : les points sélectionnés rangés le long des contours où ils sont — un contour entier, ou des points qui se suivent. Collée, une partie se **fond** dans le tracé du pays sélectionné par ses deux points les plus proches ; un contour entier s'**ajoute** (05/11 au soir).                                                                                                                                                                                                                                                                |
| **stretch** / tronçon           | Un bout de frontière entre deux sommets. Porte sa propre provenance.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **vertex** / sommet             | Un point d'une ligne. C'est ce qu'on ajoute, déplace, supprime.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **bbox**                        | Le rectangle géographique couvert. Le nôtre : O −45 / S 11,18 / E 78,75 / N 76,84.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **lon/lat**                     | Longitude, latitude. Les coordonnées du monde réel.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **(u, v)**                      | Nos coordonnées internes, de 0 à 1 sur le cadre. `u`=0 à l'ouest, `v`=0 au nord.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Mercator**                    | La projection qui transforme lon/lat en (u,v). Étire le nord — le Groenland paraît énorme.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **graticule**                   | Le quadrillage des **méridiens et des parallèles** tracé sur la carte — une ligne tous les 5° ou 10°, par exemple. Sert à lire la position d'un coup d'œil. Une couche de `{Layers}` dans la maquette, pas encore dessinée.                                                                                                                                                                                                                                                                                                                                                           |
| **even-odd**                    | La règle de remplissage : un anneau dans un anneau fait un trou. Évite de déclarer les trous.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

## Notre pipeline

| terme                                            | ce que c'est                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **DEM**                                          | _Digital Elevation Model_ — la grille d'altitudes. Notre relief vient de là.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **heightmap**                                    | Même chose, vu comme une image.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **land mask** / masque                           | Une grille de « terre ou eau ». Sépare mer et terre, ce que l'altitude ne sait pas faire.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **coupe par la terre** / land cut                | Une couleur, une hachure ou une frontière ne se montre que sur la terre du **masque** : elle s'arrête net sur sa côte, quel que soit le contour dessiné. Un contour peut donc passer en mer, et les îles qu'il englobe prennent sa couleur (CORE-421, 12/11). |
| **surface en mer** / sea surface                | La mer qu'un pays reçoit le long de ses côtes, jusqu'à une largeur donnée : chaque case de mer va au pays de la terre la plus proche, la limite entre deux voisins tombe à mi-distance, face à une terre sans pays aussi. Calculée par `files/spikes/sea-zones/rebuild.ts`, fusionnée au contour du pays ; cachée par la **coupe par la terre**. |
| **gribouillis** / scribble                       | Ce qu'un calcul de décalage laisse dans un tracé, comme le décalage d'un tracé dans Illustrator : des points inutiles, une épine (un aller-retour a → b → a), une petite boucle, deux tracés qui se chevauchent, un tracé qui se recoupe, un segment porté par plus de deux tracés (la règle : deux au plus, un dans chaque sens). Il bloque les outils de dessin ; se mesure et se nettoie (CORE-429, le dev, 13/11). |
| **raster** / rastériser                          | Transformer des lignes en grille de cases. Chaque case retient qui la possède.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **cell** / cellule                               | Une case de cette grille. La nôtre fait 1,9 km de côté.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **texture**                                      | L'image peinte qu'on pose sur le relief : parchemin, altitudes, ombrage, grain.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **feuille** / sheet                              | Le parchemin sur lequel la carte de l'atlas est imprimée : le grand rectangle beige sous tout le reste, qui déborde le relief tout autour. Il porte la bordure graduée, la marge et le titre (`scene/sheet/`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **bordure graduée** / frame                      | Le cadre qui entoure le relief sur la feuille : deux filets et une bande en blocs alternés, un bloc par degré (`graticuleFrame`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **cartouche**                                    | Sur une carte ancienne, une zone encadrée à l'intérieur de la carte pour le titre, la légende, l'échelle ou une note ; pour l'interface de l'atlas, la forme d'un panneau ou d'un cartouche d'année (`files/plans/atlas/ornament-17th-century.md`, 03/11).                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **habillage d'époque** / era skin                | L'aspect de l'interface de l'atlas pour une grande époque : couleurs, polices, ornements. **Un seul zonage, un habillage par époque** — Antiquité, Moyen Âge, Temps modernes, la frise des manuels français — choisi selon le siècle affiché. Idée du dev, 04/11 ; le 05/11 il arrête l'atlas à 1900 et n'a pas d'habillage contemporain en tête. Rien de décidé sur les bornes.                                                                                                                                                                                                                                                                                                                                    |
| **frise synchronoptique** / synchronoptic frieze | Une frise du temps à plusieurs couches parallèles (guerres, politique, personnages, civilisation…) qui montre ce qui se passe **en même temps**. Dans l'atlas : d'abord un compagnon de lecture de l'année affichée ; plus tard, un repère vers chaque année qui a sa carte. Décision du dev, 05/11. **Cinq couches** : période, guerres, politique, personnalités, civilisation ; trois formes : **l'instant** (un losange), **la durée** (une barre), **la période** (un bandeau) ; un nom et des dates, jamais de texte — le texte est au clic, dans le panneau (05/11). Modèle : Arno Peters, _Synchronoptische Weltgeschichte_.                                                                                |
| **lien de partage** / share link                 | L'adresse de l'atlas qui rouvre la même année, la même vue et le même pays en focus, copiée par le bouton « partager » de la barre en bas à droite (s16, ATLAS-138, 06/11). Pas encore construit : aujourd'hui la vue n'est gardée que dans l'onglet.                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **la carte en liste** / the map as a list        | Ce que montre la carte d'une année, en arbre — les souverains, leurs vassaux, leurs villes, leurs événements — dans un panneau qu'on parcourt au clavier et qu'un lecteur d'écran lit ; choisir une ligne fait voler la carte jusqu'à elle (s17, ATLAS-140, 06/11). Pas encore construit.                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **vignette** / printer's ornament                | Un petit élément décoratif gravé qu'on assemble avec d'autres : **coin**, **fleuron** (motif isolé), **cul-de-lampe** (motif en pointe qui ferme un texte), **filet orné** (une ligne décorée). Ce que le dev redessine dans Illustrator pour habiller l'interface de l'atlas (04/11).                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **cuirs découpés** / strapwork                   | L'ornement qui imite des bandes de cuir ou de métal découpées, enroulées et entrelacées — le décor des cartouches de cartes du Nord de l'Europe vers 1535–1630 (Vredeman de Vries, Ortelius, Hondius, Blaeu).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **style auriculaire** / auricular                | Des formes molles, lobées, comme du cartilage — le Nord de l'Europe dans la première moitié du XVIIᵉ siècle (Lutma, 1650–54), entre le maniérisme et le baroque.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **filet d'encadrement** / neatline               | La ligne imprimée qui entoure la carte, souvent double (un gras, un maigre) ; nos deux filets de la bordure graduée.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **marge**                                        | La bande de feuille entre la bordure graduée et le bord : les chiffres des degrés y sont écrits, et le titre de l'atlas en dessous.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **bake** / cuisson                               | Calculer cette image, pixel par pixel. ~1,5 million de pixels.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **noms cuits** / baked names                     | Les noms des pays d'une année placés **à la construction du site** plutôt qu'à chaque visite (ATLAS-333, 08/11) : un fichier `years/<année>/names.json` dans le site construit, jamais dans le dépôt. La page les pose **seulement si leur clé est la sienne** — l'empreinte de l'année et de tous les réglages des noms — et les place elle-même sinon (le serveur de dev, une année retouchée depuis), en le disant dans la console. Les largeurs des lettres sont lues dans le fichier de la police par `fontkit` : identiques à celles de Chrome, sauf la hauteur sous la ligne de trois lettres.                                                                                                               |
| **distances cuites** / baked band distances      | La distance de chaque point d'un pays à sa frontière et à celle de son royaume — ce qui dessine la **bande des souverains**, la **bande des vassaux** et la **bande du royaume** — calculée **à la construction du site** plutôt qu'à chaque ouverture d'une carte (ATLAS-407, approche décidée par le dev le 10/11) : 0,9 à 1,3 s de calcul par carte remplacés par un fichier `years/<année>/bands.bin` de 300 à 400 ko, compressé par la construction (l'hébergeur ne compresse pas un `.bin`). **Le serveur de dev les mesure** ; sur le site, aucun calcul de secours : un fichier qui n'arrive pas fait échouer la carte (le dev, 10/11). L'ondulation n'y est pas : elle est calculée à l'affichage. `files/plans/atlas/band-distances-at-build.md`. |
| **carte d'une date** / map of a date             | La carte qu'une date montre : **la dernière carte dessinée à cette date ou avant** — une carte reste tant qu'on n'a pas atteint la date d'une autre (le dev, 08/11) : en 1150, la carte de 1100. En reculant sous l'année de la carte montrée, on passe tout de suite à la précédente. Avant la première carte, aucune — que montrer là reste à décider. `core/data/mapOfDate.mapYearAt`.                                                                                                                                                                                                                                                                                                                           |
| **cartes préparées** / prepared maps             | Les cartes calculées à l'avance autour de celle montrée, pour que la réglette de la frise les trouve prêtes (ATLAS-333, 08/11) : la suivante dans le sens où la réglette avance d'abord, puis la plus proche de l'autre côté. **Trois cartes au plus, comme le tampon d'un lecteur vidéo** : la montrée, la précédente et la suivante (décision du dev, 08/11 au soir — un budget en mégaoctets ne se règle pas sans connaître la mémoire de la carte graphique). Une carte qui échoue à se préparer : retentée tant que l'erreur est **réparable** (le réseau), dite en console seulement quand elle est **irréversible** (un fichier absent ou illisible). **Leur préparation** (10/11, ATLAS-396, le modèle du dev) : le calcul démarre tout de suite, dans le fil d'arrière-plan, et s'inscrit au **registre des préparations en cours** — un clic sur une carte en préparation la reprend là où elle en est, jamais un second chargement ; seule la **pose** attend le calme : ni un bouton tenu **sur la carte**, ni la molette, ni une touche — le mouvement de la souris ne compte pas, ni un appui sur l'interface (la réglette de la frise se fera glisser bouton tenu). La pose en morceaux qui se met en pause et reprend reste à mesurer avant d'être construite. `core/data/mapOfDate.mapsToPrepare`.                   |
| **tint**                                         | La couleur d'un pays, appliquée dans la texture.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **derived border**                               | La frontière **calculée**, jamais dessinée à part. Calculée depuis le **bout partagé** entre deux tracés — exacte, au lieu d'une marche de 1,9 km. **Décidé le 13/10 (D1, `borders/plan.md`)** : l'atlas aussi la prend là pour une année dessinée, pour que styles et surcharges lui parviennent ; le bord des aplats du raster ne sert plus que pour les siècles encore lus dans les fichiers GPL. Les **couleurs**, elles, restent sur le raster.                                                                                                                                                                                                                                                                |
| **worker**                                       | Un second fil d'exécution. Le calcul lourd y va, pour que l'écran ne gèle pas.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **rendu à la demande** / render on demand        | Ne dessiner une image que quand quelque chose a changé — la caméra, une couche, un réglage, la fenêtre, une animation visible — au lieu d'une à chaque rafraîchissement de l'écran. Aujourd'hui l'atlas dessine en continu, 8 ms de GPU sur 16,7 même immobile : c'est ce qui fait chauffer le Mac (mesuré le 29/10, `files/plans/atlas/performance.md`). Proposé, pas décidé.                                                                                                                                                                                                                                                                                                                                      |
| **niveau de qualité** / quality level            | Un jeu de réglages qui échange de la finesse contre de la fluidité, comme dans un jeu vidéo : basse, moyenne, haute, très haute. Le standard est **très haute**, l'image d'aujourd'hui ; les autres servent une machine faible ou un ordinateur de bureau ordinaire (le dev, 29/10). Tableau des réglages sur ATLAS-305. Décidé, pas encore construit.                                                                                                                                                                                                                                                                                                                                                              |
| **méthode de flou** / blur method                | La façon dont l'atlas floute une couche, derrière un contrat commun et injectée (`scene/blur/`) : **images séparées**, chaque flou ses propres images (le standard, très haute) ; **images partagées**, une seule série pour les trois flous et un seuil d'un quart de pixel, la même image pour moins de travail, gardée pour les niveaux plus bas (ATLAS-304, 29/10).                                                                                                                                                                                                                                                                                                                                             |
| **drape** / draper                               | Poser une ligne plate sur le relief pour qu'elle épouse les montagnes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **rampe de rivage** / shore ramp                 | La bande, le long de la côte du **masque terre/mer**, où le relief redescend en douceur jusqu'au niveau de la mer (`shoreRamp`, en km, 16/10). Sans elle, le DEM est encore à des centaines de mètres là où le masque dit « côte » : chaque côte devient une falaise qui porte la couleur du pays dans la mer et cache le trait de côte.                                                                                                                                                                                                                                                                                                                                                                            |
| **biais de profondeur** / depth bias             | Ce qui garde le trait de côte visible sur le relief (16/10) : chaque point du trait est rapproché de la caméra **le long de sa ligne de visée**, donc il passe devant la terre sans bouger d'un pixel à l'écran. À distinguer du **lift**, qui soulève le trait vers le ciel : vu en biais, un trait soulevé glisse vers le haut de l'écran. Le lift est un effet voulu (le trait « posé » au-dessus du bord), le biais une garantie. Depuis le 27/10 (ATLAS-296) il sert aussi aux icônes 3D et à leur halo, d’une hauteur d’icône, et aux images plates vues de loin, d’une largeur d’image (qui suit le zoom) : la pente ne coupe plus les épées ; un massif placé entre la caméra et l'icône la cache toujours. |
| **parité éditeur–atlas**                         | La promesse que ce que le Cartographe montre est ce que l'atlas publie. Tenue en partageant la géométrie et les décisions dans `core` (frontières, ordre, couleurs, fond), chaque application ne gardant que sa façon de dessiner. L'état réel — ce qui est commun, ce qui diffère encore — est tenu dans `.claude/rules/architecture.md`, section « Editor–atlas parity » (16/10).                                                                                                                                                                                                                                                                                                                                 |
| **backdrop** / fond                              | La texture cuite, posée **sous** le canevas du Cartographe. Le seul objet géoréférencé **par construction** — c'est littéralement l'image de sortie de l'atlas, donc zéro calage et erreur nulle. Son repère est celui du **DEM**, le seul repère du canevas.                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **repère**                                       | La paire _(taille de la grille, boîte géographique)_ contre laquelle une position se calcule — on dit « projeter dans le repère du fond ». **Il se lit, il ne se déclare pas** (07/10) : les quatre coordonnées et les deux dimensions viennent du `.json` du DEM, parce qu'un repère écrit à la main est une seconde source de vérité dont l'erreur est **muette** — tout glisse, et rien ne proteste. C'est le mot derrière la phrase « sans le relief, il n'y a rien contre quoi projeter ».                                                                                                                                                                                                                     |
| **viewport**                                     | Quelle part du fond est à l'écran, et à quelle taille — **trois nombres** (`scale`, `originX`, `originY`), pas un objet vivant. Une seule échelle suffit : les pixels du fond sont carrés dans l'espace projeté à **0,031 %** près, mesuré. L'unité est le **pixel de périphérique** du canevas, pas le pixel CSS.                                                                                                                                                                                                                                                                                                                                                                                                  |
| **km par pixel écran**                           | Ce que la barre d'état affiche. Dépend de **où** on mesure, le fond étant en Mercator : 7,6 km/px à 45°N au zoom propre du fond, 10,8 à l'équateur. Le fond « lâche » quand `scale > 1` — un pixel de fond couvrant plus d'un pixel écran. **Ce n'est pas un seuil à régler.**                                                                                                                                                                                                                                                                                                                                                                                                                                      |

| **condominium**                                                    | Deux souverains sur un même territoire, sans hiérarchie. Rare, et inexprimable aujourd'hui.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **zone contestée** / contested zone                                | Un terrain que l'**histoire** a vu revendiqué par deux pays ou plus. Proposée **hachurée des couleurs de chacun**, comme chez Shepherd (idée du dev, 19/10), et dessinée à la main. Un fait historique, à ne pas confondre avec une **concordance** faible. `files/plans/evidence-system.md`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **affirmation** / claim                                            | Une seule chose dite du monde à une date : « la Flandre est vassale de la France en 1400 », « ce tronçon de frontière passe ici ». | **témoignage** / evidence                                          | Ce qu'**une** source dit d'**une** affirmation : elle la soutient ou la contredit, à tel endroit précis (une planche, une page, une déclaration Wikidata). | **concordance**                                                    | La jauge d'une affirmation, **calculée** à partir de ses témoignages, jamais saisie : à quel point elles s'accordent, pesées par leur fiabilité. | **fiabilité**                                                      | Ce que mérite une source : son **genre** (document primaire, atlas d'historien, encyclopédie, base collaborative), sa distance aux faits, son **indépendance** des autres. | **incertitude**                                                    | L'écart entre ce qu'on montre et la vérité, en **trois genres** qui n'ont jamais la même marque sur la carte : l'**imprécision** (la chose n'avait pas de bord net — le bord évanoui), le **litige** (l'histoire a eu plusieurs prétendants — la zone contestée, ou une frontière tenue de fait), l'**incertitude de savoir** (nous ne savons pas : les sources se contredisent — calculée, jamais saisie). **Sur la carte, la marque dit _ce qui_ est incertain, le panneau dit _pourquoi_** : le **flou** pour une limite incertaine, les **hachures** pour une appartenance incertaine (proposé, 19/10, d'après le flou et les hachures du dev).                                                                                                                                                                                                                                 |
| **territoire** / fief                                              | Une terre tenue d'un seul tenant : la Champagne, Blois, le Berry. L'unité stable d'une année à l'autre. Distinct de son **titulaire** et du **lien d'hommage** — notre « pays » les confond aujourd'hui (proposé, 19/10).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **titulaire** / holder                                             | La personne ou la maison qui tient un territoire : la maison de Blois-Champagne. Change à un héritage, un mariage, une confiscation, une réunion au domaine royal (proposé, 19/10).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **lien d'hommage** / bond                                          | Le titulaire, **pour tel territoire**, est l'homme de tel seigneur, à telle date. Une affirmation datée comme une autre ; un titulaire peut en avoir deux (la Flandre : la France et l'Empire) (proposé, 19/10).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **dépendance** / dependence                                        | Un territoire **dépend** d'un autre à une date : la Champagne dépend du royaume de France vers 1100. Une affirmation datée, le premier palier des vassaux directs (DESIGN-262 §8). Distincte du **lien d'hommage**, qui lie des personnes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **question** (de concordance)                                      | Ce sur quoi des affirmations se font concurrence : une même sorte d'affirmation, un même sujet, des dates qui se recouvrent — « la Champagne, vers 1100 : dépend de qui ? ». | **témoin** / witness                                               | Une source **et tout ce qui la recopie** : la carte d'Armenica.org, redessinée d'après l'atlas de Hewsen, et cet atlas font **un seul témoin**. | **chaîne de référence**                                            | Le fil qu'on remonte d'une page jusqu'à l'ouvrage dont elle est tirée : la citation sur Wikipédia, puis la référence que Wikipédia donne, puis le livre. On cite **le bout de la chaîne** ; une page sans référence se cite elle-même. C'est en la remontant qu'on voit que deux pages font un seul **témoin** (le dev, 02/11).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **arbitrage**                                                      | Le choix d'un contributeur entre des affirmations concurrentes, **signé** et **justifié** par les témoignages qui l'ont décidé. Les affirmations écartées restent conservées (proposé, 19/10).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **registre des sources** / source register                         | L'endroit de la contribution qui **liste les sources**, chacune une fois, avec son genre, sa licence, son indépendance. | **gestionnaire de sources** / source manager                       | Le registre des sources devenu outil : on y saisit une **ressource** une fois, reliée aux autres, il la **vérifie seul** et il **demande l'exploitation** à son ayant droit, sans courrier écrit à la main. ## Les outils et la méthode

| terme                                                | ce que c'est                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **spike**                                            | Un petit programme jetable pour répondre à une question. Les nôtres sont dans `files/spikes/`.                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **payload**                                          | Le contenu d'un fichier de données, une fois chargé.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **round trip**                                       | Ouvrir → modifier → enregistrer → rouvrir **à l'identique**. Le test d'un vrai éditeur.                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **façade**                                           | L'objet unique qu'un module rend au reste de l'application : une interface simple devant un sous-système compliqué. `MapLayers`, `MapPipeline`, `MapControls` (le mot du dev, 27/10 ; les commentaires du code disent encore _handle_, « ce qu'on tient pour s'en servir puis le libérer »).                                                                                                                                                                                                                                               |
| **code naïf** (et **sabotage**)                      | La version fausse mais _plausible_ d'un code — celle qu'on écrirait sans penser au piège. On la substitue un instant au vrai code : **le test écrit pour ce piège doit tomber**, lui précisément, puis on remet le vrai code. Ce n'est pas le cas nominal : c'est la preuve qu'un test garde quelque chose (règle du 27/09).                                                                                                                                                                                                               |
| **manifeste des années**                             | `years/index.json` : la liste des années dessinées et le cadre contre lequel elles l'ont été. Une année **absente** du manifeste est un fait ; une année **listée qui échoue** est une panne — les deux ne se confondent jamais.                                                                                                                                                                                                                                                                                                           |
| **mode local**                                       | Le Cartographe lancé par `pnpm dev:cartographer` : son serveur de dev écrit l'année dans `packages/atlas/public/years/<année>/` (‹ctrl+S›), et l'éditeur la rouvre au démarrage. Le site publié ne peut pas enregistrer. Arrêté le 12/10.                                                                                                                                                                                                                                                                                                  |
| **année de travail**                                 | Une année enregistrée en mode local : la copie de travail du dev, **jamais commitée** (sa décision, 12/10) — pour retrouver ses tracés, déboguer les outils, maîtriser le format.                                                                                                                                                                                                                                                                                                                                                          |
| **carte** (du Cartographe) / map                     | Un dossier de `years/`, et son nom est celui du dossier : _Ouvrir…_ les liste tous, _Enregistrer_ réécrit le sien, _Enregistrer sous…_ en crée un et continue dessus, _Enregistrer une copie_ en crée un (`<nom>.copy.<date et heure>`) et reste sur la carte en cours (le dev, 02/11 ; `cartographer/scenarii/s19`). La **carte publiée** d'une année est le dossier qui porte exactement son nom (`1100`) ; toute autre est une **carte de travail**, que l'atlas ne lit pas. Les instantanés et le brouillon sont retirés le même jour. |
| **enregistrement automatique** / autosave            | La page écrite seule, deux secondes après chaque geste, comme une carte de `years/` : `<carte>.autosave.<date et heure de l'ouverture>`, **un dossier par ouverture**, réécrit à chaque pause, **gardé** (le dev, 02/11). Après un plantage, on l'ouvre par _Ouvrir…_ comme toute carte. Remplace le brouillon et les instantanés.                                                                                                                                                                                                         |
| **enregistrement bloqué**                            | L'état où ‹ctrl+S› refuse et dit pourquoi : l'année sur disque n'a pas pu être lue, ou elle est arrivée après qu'on a commencé à dessiner. Il existe pour qu'une carte vide n'écrase jamais une année illisible.                                                                                                                                                                                                                                                                                                                           |
| **Gherkin**                                          | La façon d'écrire un scénario : _Étant donné… Quand… Alors…_. Lisible sans être programmeur.                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **snap** / accrocher                                 | Poser un point exactement sur un fleuve ou une côte qu'on possède déjà.                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **snap layer** / couche d'accroche                   | Ce que la plume suit quand elle s'accroche : la **côte** ou les **fleuves**, deux des couches de `{Layers}`. Un mode de la plume par couche. **Pas** le rail d'outils.                                                                                                                                                                                                                                                                                                                                                                     |
| **Pencil** / crayon                                  | Le mode à main levée de la plume : on appuie et on glisse, un point est posé au plus toutes les 200 ms (et seulement si la souris a bougé). Un ‹ctrl+z› reprend tout le trait.                                                                                                                                                                                                                                                                                                                                                             |
| **layer switch** / bascule vers la côte ou le fleuve | La plume simple et le crayon s'accrochent seuls à la côte **et aux fleuves** : un clic (ou un point du trait) à portée s'y pose, et la plume **passe en mode côte ou fleuve**. Si les deux sont à portée, le sommet le plus proche l'emporte ; d'une eau à l'autre, elle bascule directement. Au premier clic qu'aucune ne prend, elle **revient au mode d'où elle venait** — la plume, ou le crayon. **C'est le clic qui décide, jamais le survol** ; le survol ne fait qu'annoncer. Décision du dev, 12/10 (`s02`).                      |
| **action bar** / barre d'actions                     | La barre au pied de `{Polities}` qui porte les actions du panneau : **ajouter** et **supprimer** un pays aujourd'hui, et toute action de panneau à venir. L'en-tête du panneau n'en porte plus aucune. Décision du dev, 12/10 (`s07`).                                                                                                                                                                                                                                                                                                     |
| **group** / groupe                                   | Un pays et ses vassaux, comme un calque et ses sous-calques dans Illustrator : le suzerain au fond, ses vassaux peints par-dessus. L'empilement se change **entre frères** — entre groupes, ou entre vassaux d'un même suzerain ; un groupe bouge avec tous ses vassaux.                                                                                                                                                                                                                                                                   |
| **georeferencing**                                   | Caler une image scannée sur de vraies coordonnées. **Abandonné** — on reporte à vue.                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **TPS**                                              | _Thin-plate spline_, la déformation élastique qui sert à ça. Abandonné avec.                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Chaikin**                                          | L'algorithme qui arrondit les angles d'une ligne en escalier.                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **scalerank**                                        | Le classement d'importance d'un fleuve chez Natural Earth. Décide lesquels on garde.                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **provenance**                                       | D'où vient un tronçon et sous quelle licence. | **workbench** / établi                               | Une page du Cartographe (`/workbench.html`) où l'on monte un morceau du chrome seul, sur des données écrites à la main, pour le régler et en décider. | **plate** / fiche                                    | Une vue de l'établi : un composant dans un état donné (formulaire vide, refusé…). **Pas** la planche (supprimée le 18/10).                                                                                                                                                                                                                                                                                                                                                                                                                 |
